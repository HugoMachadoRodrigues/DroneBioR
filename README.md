# DroneBioR

DroneBioR is a research-oriented R package and Shiny app for drone biomass
analysis. It is designed to use external photogrammetry engines for the heavy
image reconstruction work, then run the scientific workflow in R.

The first version supports this architecture:

```text
ODM / ODX / WebODM / Agisoft / Pix4D outputs
  -> multispectral orthomosaic
  -> alpha or nodata mask
  -> DroneBioR QA and reflectance handling
  -> vegetation indices
  -> field data extraction
  -> biomass modeling and reporting
```

No WebODM source code is copied into this package in version 0.1.0. The package
can call ODM through Docker and can read products generated by ODM, ODX, WebODM,
Agisoft Metashape or Pix4Dmapper. This keeps the R package focused on the
scientific layer while preserving a clean legal and technical boundary with
external engines.

## Development use

From the parent project folder:

```r
pkgload::load_all("DroneBioR")

project <- dronebio_project(
  project_dir = "/Users/rodrigues.h/Library/CloudStorage/OneDrive-UniversityofFlorida/REC_Ona/Drone_Biomass"
)

result <- run_dronebio_workflow(project)
```

To start the Shiny app:

```r
pkgload::load_all("DroneBioR")
run_drone_biomass_studio(
  project_dir = "/Users/rodrigues.h/Library/CloudStorage/OneDrive-UniversityofFlorida/REC_Ona/Drone_Biomass"
)
```

## Current scope

- Read MicaSense image manifests.
- Prepare an ODM dataset folder.
- Build and run reproducible ODM Docker commands.
- Read a multispectral orthomosaic.
- Use band 6 as alpha mask when available.
- Scale reflectance-like raster values to 0-1.
- Calculate NDVI, NDRE, EVI, SAVI and NDWI.
- Export reflectance bands, spectral indices, biomass proxy and alpha mask.
- Extract raster values at field sample points.
- Fit a simple baseline biomass model.
- Provide a Shiny app prototype.
